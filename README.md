# Book Record Management System
A simple **CRUD (Create, Read, Update, Delete)** web application built with **Express.js** and **MongoDB** to manage book records efficiently. This project demonstrates backend API development, database integration, and RESTful operations.

## Features
- Add new book records with title, author, and genre.
- View all stored book records.
- Update existing book details.
- Delete unwanted book entries.
- Error handling and validation for reliable data management.

## Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose ODM)
- **Tools & Utilities:** Nodemon, Postman (for API testing)
